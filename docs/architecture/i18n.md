# I18n 身份与语言包

I18n 在 Host 呈现前将已编译文本解析为目标语言。它不改变 State 或控制流；译文只替换文本、
重排已声明的 placeholder。作者流程见[多语言](../author/i18n.md)。

```text
HIR Text / Print → I18nCatalog → 模板与 NMSG → 校验语言包及目录身份
                                                        ↓
VM 求值 placeholder → 目标语言 / fallback / 默认原文 → Semantic Text
```

## 文本身份

I18nTextId 使用区分大小写的 PassageName 和 HIR 结构路径，source 与 Span 用于定位。
相邻可见 Text、字面 print 与表达式 print 组成一条消息；不跨控制节点合并。
纯动态输出、silently 正文和 HardBreak 不建立消息；换行不能由译者增删移动。

静态成员链成为可读 placeholder，如 `$hero.profile.name`；调用、计算和动态索引使用 value_n。
VM 按源码顺序求值所有 placeholder，再填入译文，因此译文重排不会改变执行顺序。
花括号使用唯一模板语法，`{{` / `}}` 表示字面花括号。

翻译目录绑定一次有效编译。模板克隆保留身份；重新编译后必须重新校验，跨目录使用返回
DifferentCatalog / DifferentI18nCatalog。运行期索引用短哈希定位，命中后仍比较完整 ID，
碰撞回退精确查找；哈希不是持久身份。

## 包格式

```text
<locale>.nlang
├── manifest.json
├── translations.nmsg
├── dictionary.json
├── messages/*.nmsg          可选分片
└── resources/**/*.nres      可选本地化资源包
```

一个 ZIP 包对应一个 locale。manifest 包含 locale、version、game.id、game.versions 和可选 fallback；
字段与示例见[作者指南](../author/i18n.md#准备语言目录)。文件名 locale 必须与清单一致，
游戏身份使用共享的 GameIdentity / GameCompatibility 校验。

消息文件按路径排序合并，ID 全局唯一。NMSG 由 `:: id`、`[source]`、`[translation]` 与可选
`[values]` 组成，dictionary.json 保存全部命名字典。包内不接收 CSV、PO、脚本或新的表达式。
清单当前没有独立 format_version 字段。

## 两层验证

1. Binding 限制 ZIP 大小、解压总量、单文件大小和条目数，交付内存条目。
2. Core 验证安全路径、文件白名单、重复条目、UTF-8、清单与目标游戏。
3. NMSG 合并拒绝未知/重复 ID、source 修改、非法 section 和重复 values。
4. 当前 I18nCatalog 再验证语言、placeholder 集合及动态字典，绑定本次编译身份。

包级可信不等于可用于任意编译目录，后两层不能合并省略。包验证后释放原始消息 bytes，
结构化消息和已验证模板通过 Arc 共享，仅本地化资源包保留资源字节。
I18n 包模块不负责安装目录；ZIP 容器 IO 留在外围装载与发布代码。

## 回退、字典与更新

I18nLanguageChain 按 manifest 选择完整 fallback 链，拒绝重复 locale、缺失 fallback、
顺序不一致或任意无效模板。某层缺少消息或 text 为空才进入下一层，最终回到原文。

placeholder 可以关联命名字典，只有实际 String 值查字典；Number、Boolean、Null、Undefined
按显示规则插入。字典缺项保留原字符串，不修改 State 中的值。

导出合并保留同语言且 placeholder 兼容的旧译文和字典，新消息进入模板；删除或不兼容条目
进入 Removed / Incompatible 报告，不混回可运行模板。跨语言合并返回 LanguageMismatch。

语言选择跨 Engine continuation 共享，不复制整份消息树。Session 成功切换后通过
RefreshCurrent 重绘正文与公共区域，事务规则见[运行时](runtime.md#随机历史与重绘)。
动态 Macro 输出与导航标签尚无自动编译期文本身份，不能通过扫描运行期字符串补造身份。
